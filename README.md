# Quester Sunday School Hub

Static review build for the 13-week Quester Sunday School curriculum.

## Open Locally

Run a simple static server from the parent folder:

```bash
python -m http.server 8765
```

Then open:

`http://127.0.0.1:8765/Quester_SundaySchool_Hub/`

## GitHub Pages

This folder is intended to be publishable as a static site. In GitHub Pages, set the Pages source to this folder if your repo setup supports it, or make this folder the repo root.

## Included

- Weekly Hub interface
- Weekly leader guide print pages
- Puzzle Lab
- Coloring PDFs only
- CREW and DOODS student journal PDFs, color and printer-friendly
- Links to the live Identity Island game demo

## Not Included

Large local MP4 music/VBS files are not included. Time-gated VBS clip buttons show a video-upload note and link to the official Quester video library instead.

Coloring source sketches such as JPG, PNG, and SVG production files are intentionally not included in the coloring PDF resource path.

The Digital Quest button links to the existing hosted demo:

`https://jugemz.github.io/quester-demo/`
