# Quester Sunday School DOODS Journals

These PDFs are one-page, weekly, student-facing preteen journals for ages 11-12.

They use deeper reflection prompts, discussion questions, Scripture field notes, and a practical next-step response.

Generated files:

`Quester_DOODS_Journal_Week_01.pdf` through `Quester_DOODS_Journal_Week_13.pdf`

Printer-friendly versions:

`Quester_DOODS_Journal_Week_01_PrinterFriendly.pdf` through `Quester_DOODS_Journal_Week_13_PrinterFriendly.pdf`

Regenerate them from the project root with:

`node Quester_SundaySchool_Hub/tools/generate-doods-journal-pdfs.js`
